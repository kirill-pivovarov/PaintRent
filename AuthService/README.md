
# 🔐 AuthService — Сервис аутентификации и сессий

Микросервис платформы **PaintRent**, отвечающий за регистрацию пользователей, управление жизненным циклом сессий, выпуск JWT-токенов доступа и защиту от компрометации сессий (Refresh Token Rotation & Reuse Detection).

---

## 📋 Предварительные требования

Перед началом работы убедитесь, что у вас установлены:
* **Python** версии 3.10+
* **PostgreSQL** (локально или в Docker-контейнере)

---

## 🚀 Пошаговая инструкция по настройке и запуску

### 1. Подготовка базы данных
Создайте отдельную базу данных для сервиса авторизации (через `psql`, pgAdmin или DBeaver):

```sql
CREATE DATABASE paintrent_auth;
```

---

### 2. Переход в директорию сервиса
Откройте терминал в корне проекта и перейдите в папку `AuthService`:

```bash
cd AuthService
```

---

### 3. Настройка виртуального окружения

Создайте изолированное окружение Python:
```bash
python -m venv .venv
```

Активируйте виртуальное окружение:

* **Windows (PowerShell):**
  ```powershell
  .\.venv\Scripts\Activate.ps1
  ```
* **Windows (CMD):**
  ```cmd
  .\.venv\Scripts\activate.bat
  ```
* **Linux / macOS:**
  ```bash
  source .venv/bin/activate
  ```

---

### 4. Установка зависимостей

Обновите менеджер пакетов и установите все необходимые библиотеки:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

---

### 5. Настройка переменных окружения

Создайте в папке `AuthService` файл **`.env`** (на основе `.env.example`):

```ini
# Подключение к БД (для Windows рекомендуется использовать 127.0.0.1 вместо localhost)
DATABASE_URL=postgresql+asyncpg://postgres:postgres@127.0.0.1:5432/paintrent_auth

# Настройки безопасности JWT
JWT_SECRET_KEY=your_super_secret_jwt_key_32_bytes_length
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=15

# Настройки сессий
REFRESH_TOKEN_TTL_DAYS=30
```

> 💡 **Генерация секретного ключа:**  
> Сгенерировать надежный 32-байтный ключ можно командой:  
> `python -c "import secrets; print(secrets.token_hex(32))"`

---

### 6. Применение миграций базы данных

Создайте структуру таблиц в базе данных с помощью Alembic:

```bash
alembic upgrade head
```

---

### 7. Запуск сервиса

Запустите сервер приложения:

```bash
python -m app
```

После успешного старта приложение будет доступно по адресу:  
👉 **`http://127.0.0.1:8000`** *(или указанный в конфигурации порт)*

---

## 📖 Документация API и проверка работы

Интерактивная документация Swagger UI с возможностью отправки запросов генерируется автоматически:

* **Swagger UI:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
* **ReDoc:** [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

### Основные эндпоинты:
| Метод | Путь | Описание |
| :---: | :--- | :--- |
| **`POST`** | `/api/v1/auth/signup` | Регистрация нового пользователя с выпуском пары токенов |
| **`POST`** | `/api/v1/auth/login` | Аутентификация по логину/паролю и открытие новой сессии |
| **`POST`** | `/api/v1/auth/refresh` | Ротация токенов обновления и проверка на компрометацию сессии |
