# PaintRent # Шпаргалка: Как запустить и проверить API

## 1. Запуск сервера
```bash
uvicorn app.main:app --reload
```
* **Swagger UI (документация):** http://127.0.0.1:8000/api/v1/docs

---

## 2. Эндпоинты в Swagger

### Authentication (Аутентификация)
* **POST /auth/register** — Регистрация. 
  * Для создания картин укажите `role: PARTNER`, для обычных пользователей — `role: CLIENT`.
* **POST /auth/login** — Логин (возвращает **access_token**).
  * Введите email в поле `username` и пароль.
* **Как авторизоваться в Swagger:**
  1. Нажмите кнопку **Authorize** (замочек справа вверху).
  2. Введите почту **Username** и пароль **Password**.
  3. Нажмите **Authorize**, затем **Close**.
* **GET /auth/me** — Проверка токена. Возвращает профиль текущего пользователя.

### Paintings (Картины)
* **GET /paintings/** — Каталог всех картин (работает без токена).
* **GET /paintings/{id}** — Карточка конкретной картины.
* **POST /paintings/** — Создание картины (только для `PARTNER` или `ADMIN`).
* **PATCH /paintings/{id}** — Изменение картины (только для владельца-партнера).
* **DELETE /paintings/{id}** — Удаление картины.

---

## 3. Краткий сценарий проверки

1. **Регистрация партнера:** Создайте пользователя с `role: PARTNER`.
2. **Авторизация:** Залогиньтесь через кнопку **Authorize**.
3. **Создание контента:** Добавьте картину через `POST /paintings/`.
4. **Регистрация клиента:** Создайте пользователя с `role: CLIENT` и авторизуйтесь под его токеном.
5. **Проверка прав:** Попробуйте клиентом создать картину — Swagger должен вернуть ошибку `403 Forbidden`.
6. **Проверка чтения:** Выполните запрос `GET /paintings/` под клиентом — каталог должен успешно отобразиться.
